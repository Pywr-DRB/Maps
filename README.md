# Maps

Contains scripts for generating maps of the Delaware River Basin, with focus on water resources systems infrastructure modeled by Pywr-DRB. 

# Data

Multiple datasets are necessary to generate the maps including:
- State boundary shapefiles
- Basin boundary shapefiles
- Pywr-DRB model nodes
- etc. 


Burrow boundaries used make_AmestoyEtAl_2026_map.py in are downloaded from:
https://www.nyc.gov/content/planning/pages/resources/datasets/borough-boundaries

These files are too large to host on GitHub. Contact Trevor to recieve the necessary data.
